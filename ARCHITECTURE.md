# Framework Computer

Battery charge limit: `sudo framework_tool --charge-limit <percent>` (0–100; 0 = no limit).

# Niri Hotkey Config

Hotkeys in `.config/niri/config.kdl` lines 350–633 under `binds { }`.

Search: `grep "action-name" ~/.config/niri/config.kdl`. Format: `Mod+Key { action; }` (Mod = Super key).
